## 🚀 Getting Started

To explore any of these projects:

1. Clone this repository:
```bash
git clone https://github.com/WebCraftPhil/Data-Analyst-Portfolio.git
cd Data-Analyst-Portfolio
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Navigate to the project folder of interest and open the notebook
